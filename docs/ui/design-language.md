# Notesteme UI 設計語言

> 狀態：草案 v0.1（2026-11-11）
> 相關文件：[UI 規格總覽](README.md)、[頁面規格](pages.md)、[ADR-0008](../adr/0008-web-ui-architecture.md)

## 1. 題材、使用者與主要任務

- **題材**：把影片和 Podcast 變成字幕和知識筆記。處理的每一樣東西都有時間座標：字幕句、章節、關鍵畫面、處理進度。
- **使用者**：一位技術背景的使用者，每天使用。用它追蹤技術頻道、準備職涯筆記，最後在 Obsidian 裡閱讀成果。
- **主要任務**：
  - 一眼看出哪些內容處理好了、哪些卡住、卡在哪一段。
  - 從列表快速進入某部影片的字幕、畫面或筆記。
  - 反覆調整 prompt 與處理方案。

## 2. 設計概念：燈箱與時間帶

剪接師會把底片條和印樣（contact sheet）攤在燈箱上，用色筆圈出要用的格子。Notesteme 沿用這個工作場景：

- **燈箱**：冷調、均勻發光的工作台面。介面本身很安靜，內容才是主角。
- **時間帶**：每部影音都畫成一條「和它自己的長度等比例」的帶子，上面疊著說話密度、章節、關鍵畫面和處理進度。這是整個介面**唯一大膽的元素**，出現在媒體庫、影音詳情、佇列和訂閱預覽中。
- **黃色記號**：取自傳統字幕的黃色，只用來標示「現在」和「被選中」，包括播放頭、目前的字幕句、選中的畫面。

其餘部分都保持安靜：沒有漸層、沒有裝飾性插圖，也不在每張卡片下方放陰影。

### 3.4 Token 命名

```css
--color-opal / --color-sheet / --color-ink / --color-pewter / --color-cue / --color-signal / --color-fault

--surface-app      /* Opal | Booth */
--surface-panel    /* Sheet | Panel */
--text-primary     /* Ink | Paper */
--text-secondary   /* Pewter | Pewter Dim */
--mark-now         /* Cue：播放頭、目前句、選中 */
--surface-hover    /* Ink 5% | Paper 5%：hover 底色 */
--state-done       /* Ink | Paper：處理中的 chunk、等待 Agent 的虛線 */
--state-done-quiet /* Ink 34% | Paper 34%：已完成的步驟帶，刻意保持安靜 */
--state-pending    /* Pewter：虛線 */
--state-failed     /* Fault */
--state-ok-text    /* Signal */
--rule             /* Pewter 24% */
--density-fill     /* Ink 14% | Paper 12%：說話密度的面積 */
--density-line     /* Ink 55% | Paper 55%：說話密度的輪廓線 */
--chapter          /* Ink 40% | Paper 38%：章節線 */
```

## 4. 字體

### 4.1 字族

| 角色 | 字體 | 說明 |
|---|---|---|
| 介面（拉丁字母與數字） | **Barlow**（SIL OFL，自架 woff2） | 源自公路標誌的 grotesk，帶有設備面板與標示的語感。標題與時間碼用 Semi Condensed 寬度 |
| 介面（中文） | 系統黑體，依語言選擇 | 見下方字型堆疊 |
| 閱讀 | **Source Serif 4** + Noto Serif TC／SC | 只用在閱讀區：筆記預覽、字幕閱讀模式。用 Fontsource 的 unicode-range 切片版本，按需載入 |
| 程式碼 | 系統等寬字體 | 只用在 prompt 編輯器與 JSON 檢視 |

- 時間碼、時長、金額一律用 Barlow 的 `font-variant-numeric: tabular-nums`。**不用等寬字體顯示小型資料標籤。**
- 已在 mockup 中驗證：Barlow 支援 `tnum`。開啟後「1111」與「0000」的寬度相同；未開啟時寬度差了約 60%。

### 4.2 依語言的字型堆疊

同一個漢字在繁中、简中、日文中的字形不同。`<html lang>` 要跟隨 UI 語言，內容元素則標上內容自己的 `lang`（例如简中的影片標題、字幕）。

只在 `:root` 設定一次字型堆疊是不夠的：子元素繼承的是已經解析好的 `font-family`，所以繁中頁面裡的简中標題仍會用繁中字形。mockup 改用下面的寫法，讓每個元素都依自己的語言重新解析：

```css
:root          { --family: "Barlow"; }
:lang(zh-Hant) { --cjk: "PingFang TC", "Microsoft JhengHei UI", "Noto Sans CJK TC", "Noto Sans TC"; }
:lang(zh-Hans) { --cjk: "PingFang SC", "Microsoft YaHei UI", "Noto Sans CJK SC", "Noto Sans SC"; }
*              { font-family: var(--family), var(--cjk), sans-serif; }
.cond          { --family: "Barlow Semi Condensed"; }  /* 元件只改 --family，不直接寫 font-family */
```

### 4.3 字級（沿用 Bringhurst 的傳統級數）

| 級數 | 用途 |
|---|---|
| 12 | 時間帶上的時間碼、表格中的次要資訊 |
| 14 | 介面預設：控制元件、表格 |
| 16 | 字幕句、閱讀內文（中文最小 16） |
| 18 | 區段標題 |
| 21 | 抽屜標題 |
| 24 | 頁面標題（Barlow Semi Condensed 600，字距 −0.01em） |
| 36 | 影音詳情頁的影片標題 |

- **字重**：400 內文、500 介面強調、600 標題，不使用其他字重。
- **行高**：
  - 拉丁字母介面 1.4、中文介面 1.6。
  - 閱讀區：中文 1.8、拉丁字母襯線 1.6。
- **行長**：閱讀區中文最多 38 字（`max-width: 38em`），英文最多 66 字元。
- **大小寫**：一律用 sentence case。不用全大寫標籤，也不在標題上方加小標籤（eyebrow）。

### 5.1 App 外框

```

│           │                                                              │
│ [ 新增 ]  │ （頁面內容，靠左對齊）                                        │
│           │                                                              │
│ 總覽      │                                                              │
│ 媒體庫    │                                                              │
│ 訂閱      │                                                              │
│ 佇列    3 │                                                              │
│           │                                                              │
│ 調整      │                                                              │
│ Prompt    │                                                              │
│ 處理方案  │                                                              │
│ 字幕樣式  │                                                              │
│ 筆記模板  │                                                              │
│           │                                                              │
│ 系統      │                                                              │
│ 成本      │                                                              │
│ 設定      │                                                              │
│           │                                                              │
│ 需要你處理 2 │                                                           │
└───────────┴──────────────────────────────────────────────────────────────┘
```

- 左側導覽：展開時 200px，收合時 64px（只剩圖示，hover 顯示名稱）。
- 導覽分成三組：工作、調整、系統。分組名稱是真實的資訊，不是裝飾，所以保留。
- 「需要你處理」固定在導覽底部，數量為 0 時隱藏。

### 5.2 格線與間距

- 以 4px 為基準，常用值為 8、12、16、24、32、48。
- 表格與列表佔滿內容寬度；閱讀區用 38em；表單最寬 640px。
- 一律靠左對齊。數字、時間碼、金額在表格中靠右對齊。

### 5.3 圓角與層次

| 層級 | 圓角 | 例子 |
|---|---|---|
| 記號 | 2px | 時間帶、選中畫面的框 |
| 控制元件 | 4px | 按鈕、輸入框、篩選條件 |
| 容器 | 8px | 面板、抽屜、對話框 |

- 層次靠色調建立：Sheet 放在 Opal 上。
- 只有浮在上層的元素（抽屜、popover、指令面板）有陰影，而且只有一種：`0 8px 24px rgb(31 42 58 / 0.16)`。
- 分隔線只用在「分隔不同群組」的地方，例如媒體庫中依頻道分組的邊界。

### 5.4 圖示

用 Phosphor Icons 的 Regular 線條粗細，尺寸 20px，與文字一起出現時用 16px。圖示不單獨表達狀態。

### 5.5 介面密度

（2026-11-25，依 /goal 由實作者暫定，待 owner 追認）pages.md §12 的「外觀」分區有「介面密度」，這份文件原本沒有定義，所以先定兩檔：

| 密度 | 適用 | 規則 |
|---|---|---|
| 舒適（預設） | 所有畫面 | 就是 5.2 的間距，現在的樣子 |
| 緊湊 | 列表與表格 | 表格儲存格（`.data-table`、`.settings-table`）與虛擬列表的列（媒體庫 `.lrow`、佇列 `.trow`）的上下留白改成 4px；Prompt 庫、處理方案、字幕樣式等清單的列（`.tune-row`）改成 8px |

- 緊湊只縮小上下留白，不改字級、`--space-*` token、左右留白與其他元件；按鈕維持自己的最小高度（32px），所以按鈕仍不小於 24px（WCAG 2.2 的 2.5.8）；表格與列中的連結、勾選框本身可能小於 24px，合規靠 2.5.8 的間距例外：每列的高度是上下各 4px 加上至少一行文字（14px 字級），相鄰列的目標中心距離大於 24px。顏色不變，對比不受影響。
- 選擇存在瀏覽器（localStorage `notesteme.density`，和主題同一個機制），套用為 `<html data-density="compact">`；舒適時不設屬性。CSS 在 `web/client/src/styles/density.css`。
- 閱讀區（字幕句列表、筆記）不受密度影響：它們是閱讀而不是瀏覽，行距由 §4 決定。

## 6. 核心元件

### 6.1 時間帶（Time Ribbon）

時間帶的橫軸就是影音本身的時間軸。

**圖層**（由下往上）：

| 圖層 | 內容 | 表現 |
|---|---|---|
| 底軌 | 影音全長 | `--surface-app` 色調（放在 Sheet 上），2px 圓角，不加外框 |
| 說話密度 | 每個時間區間的平均說話速度（字數／秒，依重疊時間加權） | 平滑的面積輪廓：`--density-fill` 填色加 1px `--density-line` 輪廓線。沉默會讓輪廓下降。還沒轉錄的部分只畫一條點狀基線 |
| 章節 | 章節起點 | 1px `--chapter` 直線；`###` 小節只畫下半段；hover 顯示章節名稱 |
| 處理範圍 | 正在處理或失敗的時間範圍（只在完整版） | 底軌上淡淡的 Ink 8% 或 Fault 12% 區塊，對應下方步驟帶的位置 |
| 步驟帶 | 字幕、校正、翻譯（依處理方案顯示） | 底軌下方；精簡版每條 3px、間隔 2px；完整版每條 6px，右側 112px 欄位放逐列對齊的標籤 |
| 畫面 | 候選與選中的畫面 | 候選：底軌下方 1px Pewter 刻度；選中：底軌上方 6px Cue 三角，加 1px Ink 邊 |
| 播放頭 | 目前播放位置（只在詳情頁） | 2px Cue 直線，加 1px Ink 邊，可以拖曳 |

**步驟帶的狀態**：

| 狀態 | 表現 | 文字 |
|---|---|---|
| 完成 | `--state-done-quiet` 實心，刻意保持安靜 | 完成 |
| 處理中 | 已完成的 chunk 依它的時間範圍，用和「完成」相同的淡色填實；目前的 chunk 用 Ink 顯示「顯影」動畫；其餘為 Pewter 虛線 | 校正 9/16 |
| 等待 Agent | Ink 實色長虛線 | 等待 Agent |
| 需要你處理 | Ink 實色點線 | 需要你處理／超出預算／等你決定 |
| 稍後檢查 | Pewter 點線，和「未開始」的虛線區分；tooltip 顯示下次檢查的時間 | 稍後檢查 |
| 失敗 | 失敗 chunk 的時間範圍用 Fault 加白色斜線紋 | 失敗：第 7 段 |
| 略過 | 不顯示這條帶子，tooltip 說明 | 已略過 |

LLM 的 chunk 本身就對應影片中的時間範圍，所以進度可以畫在實際的時間位置上。使用者看得到**是影片的哪一段**卡住了，不只是一個百分比。

強弱的分配原則：已完成是常態，所以很安靜；只有例外狀態（處理中、失敗、等待 Agent、需要你處理）使用強色。一頁的媒體庫掃過去，目光會自動停在需要注意的列上。

**尺寸**：

- 精簡版：底軌 24px 加上步驟帶，用在媒體庫的列、佇列、訂閱預覽。步驟帶太細，放不下逐條標籤，文字改放在列右側的狀態欄。
- 完整版：底軌 72px，加上時間刻度（Barlow Semi Condensed 12px），用在影音詳情頁的頂部，同時當作播放器的拖曳軸。

**互動**：

- Hover：顯示時間碼、章節、那個時間點的字幕句。
- 點擊：在詳情頁會跳到該時間；在媒體庫會打開詳情頁並定位到該時間。
- 在完整版上拖曳：選取一個時間範圍，可以「只重新校正這段」或「複製這段字幕」。
- 鍵盤：
  - `←`／`→`：播放頭移動 5 秒。
  - `Shift + ←／→`：跳到上一個或下一個章節。
  - `Shift + 拖曳` 或 `Shift + 方向鍵`：選取範圍。（2026-11-25，依 /goal 由實作者暫定，待 owner 追認：和上一行的 `Shift + ←／→` 衝突，實作取「跳章節」，範圍選取只用指標拖曳，見 [README 10.26](README.md#1026-影音詳情與媒體庫列的規格缺口2026-11-25) 第 3 點。）

**無障礙**：

- 精簡版是 `role="img"`，`aria-label` 寫出摘要，例如「字幕完成，校正 9/16 段，翻譯未開始」。
- 完整版是 `role="slider"`，`aria-valuetext` 是時間碼。
- 媒體庫的同一列也有文字版的狀態欄。

**特殊情況**：

- 只有音訊的內容沒有畫面圖層。
- 直播中、還沒有長度的內容：只顯示「直播中」文字，不畫帶子。

### 6.2 字幕句列表

```
  06:22   應該是提高工作效率的
▌ 06:25   比如說 daily stand-up                      ← 目前句：左側 3px Cue 條
  06:26 ◦ 原本的目的是提升團隊的資訊同步             ← ◦ 表示時間由停頓推算
```

- 時間碼靠右對齊、用 tabular 數字、Pewter 色；點擊時間碼會跳到該時間。
- 顯示模式：
  - 原始、校正、譯文。
  - 對照：原文 Ink，譯文 Pewter，上下兩行。
  - 差異：刪除的文字加刪除線並用 Fault 色，新增的文字加底線並用 Signal 色。除了顏色，也一定有文字裝飾。
- 時間來源不是 `source` 的字幕句，在時間碼旁加空心小圓點，tooltip 說明時間怎麼來的。
- 播放時自動捲動，讓目前句保持在視窗中間偏上；使用者手動捲動後停止自動捲動，並顯示「回到目前位置」按鈕。

### 6.3 印樣（關鍵畫面）

- 依時間順序排成格狀，每格 16:9，下方顯示時間碼。
- 選中的畫面：3px Cue 框加 1px Ink 外框，下方顯示圖說。
- 沒選中的候選畫面：72% 不透明度。不用灰階，因為灰階會讓人無法判斷畫面內容。
- 點擊畫面會跳到該時間；按 `Space` 放大檢視。
- 格子的編號是真實的時間順序，所以保留。

### 6.4 狀態用語

| 狀態 | 圖示 | 繁中 |
|---|---|---|
| `pending` | 空心圓 | 等待中 |
| `running` | 半實心圓 | 處理中 |
| `waiting` | 時鐘圖示 | 稍後檢查 |
| `awaiting_agent` | Agent 圖示 | 等待 Agent |
| `done` | 實心勾（Signal 色；文字用次要色，保持安靜） | 完成 |
| `skipped` | 斜線圓 | 已略過 |
| `failed` | 叉號 | 失敗 |
| `blocked`（原因 `needs_action`） | 驚嘆號 | 需要你處理 |
| `blocked`（原因 `budget_blocked`） | 錢包圖示 | 超出預算 |
| `blocked`（原因 `awaiting_user`） | 問號圖示 | 等你決定 |

### 6.5 按鈕與回饋

- 主要按鈕：Ink 底、Sheet 字、4px 圓角。一個畫面最多一個主要按鈕。
- 次要按鈕：只有文字，hover 時加底線。
- 危險操作：Fault 色文字，執行前先確認，並說明會失去什麼。
- Toast：出現在左下，Ink 底，5 秒後消失；可以有一個動作按鈕（例如「復原」）。
- 抽屜從右側滑出，用於新增、快速檢視與編輯。

## 7. 動態

- 回應使用者操作：hover 與按下用 120ms ease-out；抽屜與面板用 200ms（位移 16px 加淡入）。
- **唯一主動出現的動畫是「顯影」**：步驟帶中正在處理的 chunk 範圍內，有一道柔和的 Ink 漸層由左往右掃過，週期 1.6 秒。這個動畫本身就帶有資訊：它指出正在處理影片的哪一段。
- 步驟完成時，那段帶子在 200ms 內填實，告訴使用者狀態改變了。
- 其他元素都不會自己動：沒有區塊進場動畫，卡片 hover 也不浮起。
- `prefers-reduced-motion`：顯影改成靜態斜線紋，所有狀態變化立即完成。

## 8. 取捨紀錄（對照常見套版樣式的修正）

### 8.1 Mockup 第一輪的修正（2026-11-12）
